# 30元预算与安全边界

## 计费保护

- 全项目累计上限CNY30，默认每次基准批次上限CNY0.50、单任务上限CNY0.25。
- 每条准则调用前，在SQLite事务中预留保守的完整输入与最大输出费用；并发不能同时花同一笔余额。
- 输入按UTF-8字节上界加2048 framing cushion，不使用不可靠的“字符数除4”；输出按max_tokens预留。
- 超时、非200和用量不明的请求保留整笔预留，避免重试低估；默认一次尝试，最多配置两次且每次重新预留。
- 成功返回合法usage才释放剩余预留。若usage超过预留，冻结后续付费调用，需排查。
- 不采用缓存命中或低峰折扣估价。价格、汇率、token边界和外部账户活动仍会影响真实账单，因此这是保守控制，不是服务商账单担保。
- 不要删除或重置`data/jury.sqlite`费用账本。该账本只约束此项目，不约束同一个Key在其他程序中的使用。

核对日期2026-10-24；官方：https://api-docs.deepseek.com/quick_start/pricing/

当前Flash API名`deepseek-flash`。官方峰值cache-miss输入USD0.30/百万token、输出USD1.20/百万token。项目取USD/CNY规划上界8并增加25%余量，采用CNY3.00/百万输入、CNY12.00/百万输出。

这不是实际人民币汇率或人民币报价。`deepseek-v4-pro`不能使用Flash费率；程序要求其保守费率至少CNY13.20/39.60每百万输入/输出。价格核对到期日默认2026-10-31；过期停止收费请求，不能自动刷新后继续花费。
