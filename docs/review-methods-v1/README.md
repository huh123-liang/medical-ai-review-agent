## 架构位置

现有主线：冻结输入/准则 → 单Jury → 程序校验/汇总 → 审计。

本轮：在主线之外，规定如何记录任务、义务、断言、来源支持与未决项。既有影子层保持默认关闭，没有线上接线。

未来候选：任务与准则适用性 → 绑定必检项 + 检索可选项 → 少量已审核示例 → 单Jury逐项判断 → 来源支持复核 → 确定性校验/审计。后三类知识逻辑分开：Rubrics、医学事实来源、审核示例；医生标签只在独立评测端。不是本轮已实现的三级通用库、多Agent或MCP。
