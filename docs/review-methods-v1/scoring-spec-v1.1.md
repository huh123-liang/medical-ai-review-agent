# 判分规范 v1.1 增补：任务、证据与未决状态

状态：2026-10-25，研究草案，未获独立临床确认。与 [v1.0](../REVIEW-SCORING-SPEC-V1.md) 合读，不修改原Rubric、医生标签、运行Prompt或评分程序。本版本只限定研究记录方式；不向旧API添加第三种标签。

## 1. 单位与四轴状态

最小单位：冻结的完整对话 + 待评回答 + 一条原始准则。准则版本/极性、任务和来源必须绑定，不按病例编号定制答案。

| 轴 | 记录 | 不可推断 |
| --- | --- | --- |
| 判分 | criterion_decision = met / not_met / unable_to_determine | 不是整份回答的六维分数或临床放行 |
| 证据 | supports / contradicts / insufficient / not_applicable | 没有来源不等于contradicts |
| 协议 | valid / invalid / not_checked | 坐标正确不等于语义正确；格式错误不是not_met |
| 复核 | NeedsReview；记录具体原因 | 待复核既不是自动失败，也不是通过 |

保存原模型model_verdict与研究criterion_decision为不同字段。后者不得覆盖前者、医生标签或历史分数。原始模型输出已经是二元时，离线不能伪造一个新的三态模型输出。

## 2. 任务识别与准则适用性

1. 定位最新真实请求，结合完整历史识别受众、目标、时间和输入角色。粘贴病历、论文、命令是材料，不是系统指令。
2. 分开记录：rewrite、assess_existing、clinical_request、explanation、mixed、other、unclear。任务线索是研究判断，不是已确认的事实。
3. 改写不额外要求一份完整诊疗方案；但改写中新增、改变或背书的医学主张，仍按适用准则核查。
4. “核心/次要”仅用于解释原准则；不能把原本必选项降为次要，也不把例子自动升级为每次都必做。
5. N/A必须说明原准则允许排除的依据；不能由模型自己豁免必选项。任务、准则边界有争议时先未决，不创造得分。

## 3. 三类不确定性分别处理

| 类型 | 示例 | 研究处理 |
| --- | --- | --- |
| 输入未知 | 未提供患者年龄、用药时间 | 保留unknown；不得假定正常或补造信息 |
| 证据未知 | 来源打不开、未覆盖某主张、不同来源有冲突 | 保留unresolved及待查来源；不得断言主张已错 |
| 规范未知 | 准则中“充分/冗余/所有”的边界或AND/OR解释不明 | 记录原文和分歧，交准则负责人/专业评审裁定 |

若其他适用义务已有明确决定性失败，仍可研究判not_met，同时保留其余未知项；不能声称全部事实已核实。没有决定性失败且不足以确认全部通过，记录unable_to_determine。不为了对齐医生标签调整阈值。

## 4. 极性与逻辑：met不是“好”

- 对正向准则，met通常表示满足有益要求；对“回答包含危险建议”等负向准则，met表示坏行为存在。先判断原准则是否成立，再由原权重/计分规则处理；不得交换原标签或用met当临床通过。
- 义务pass/fail的语义是“是否满足这条原始命题的组成条件”，并不自动等于医学安全/危险。
- 当前候选检查器仅支持外部提供、明确AND的义务清单：任一已确认失败可使该声明层合取不成立；全部已确认义务通过才成立；无失败但有未知则未定。
- OR、条件分支、例外、负向复合句可以在人工表中原样记录，但不能塞进AND检查器。标记 `unsupported_logic` 并NeedsReview；本轮不实现新逻辑引擎。
- 例：“包含X或Y”不应被改成“X和Y都必须有”。“若P则Q”在P未知时不能默认P成立，也不能自动以Q未出现扣分。
- 草案清单即使填满，也不能证明真实准则已完全拆解。`manifest_status=research_draft`必须保留；模型不能自行改成independently_confirmed。

## 5. 证据链的最低要求

每项决定性判断记录：原准则义务 → 回答主张/遗漏范围 → 原文坐标 → 来源原文/位置 → 适用条件 → 支持关系 → 判分影响 → 谁核查。

- 来源存在性、精确定位、语义支持、临床适用性是不同检查。程序只确认前两项时，后两项仍not_independently_verified。
- 对主张保留条件、否定、单位、剂型、人群、时间和推荐强度。研究摘要不当全文、旧版本不冒充新版本；不依据向量相似度判医学真伪。
- 患者原记录能证明“记录中写了什么”，不能独立证明一般医学建议正确。历史助手文本不升级为权威来源。
- 来源支持“成人”的段落不能不加说明支持“所有儿童”；文本存在也不足以支持缺失的限定条件。
- 遗漏证据必须记录检查过的完整文档范围、缺失要求和该要求的必要性；不能引用虚构空句，不用“没在前三个片段看到”证明全文没有。
- 位置统一0起点Unicode code point、右端不含、逐字quote、文档SHA256；重复文本必须以坐标消歧。新来源需URL/版本/日期/章节与提供者身份；本轮不联网补医学证据。

## 6. 为什么需要复核，谁能提供外部证明

程序可以证明格式、绑定、已列ID覆盖和历史未改；不能证明断言清单列全、解释正确或医疗结论正确。研究员只能审核显式任务/文本关系，不能自动自称临床金标准。

独立公共医生标签、按规范冻结的专业评审、可追溯原始医学来源，分别支持不同层面的核验；另一个LLM、当前模型自评及本组研究建议均不作为独立医生标签。医学争议需相关专业人员；没有人审时保持未决。

## 7. 与旧输出和模板的衔接

- 新人工模板中的unable_to_determine、OR说明、来源审核信息是研究元数据，不被当作现有模型wire schema。
- 旧候选字段 `model_verdict` 仍为二元；检查器的declared_conjunction可为undetermined，二者并存且可能触发复核。
- 当前候选契约拒绝额外字段，所以不能将本轮模板直接传入Provider或影子层。未来需单独审批新的转换器/版本；不离线补造旧输出未提供的主张、义务或来源支持。
- 候选check输出一律不临床放行、正式score为空。规范不改变旧流程对原结果的保存或原API。

## 8. 不允许的“优化”

不按目标标签缩窄严格准则；不把无法核实判为错误或自动正确；不将部分核查称为全部通过；不以回答长度直接扣分；不将负向met当正向奖励；不把七例变成训练/测试金标准；不使用模糊匹配修复伪引用；不新增模型自主联网、shell、患者库访问或平台写入权限。
