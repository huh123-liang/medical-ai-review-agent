# 第5轮：复杂回答准则边界与未见开发样本

授权范围：复核复杂回答准则、修复退步、补充本项目未评测的开发样本。原MVP2、GitHub和现有向量索引不动。开始账本2.427675元/366次请求，总上限仍30元。

## 1. 准则原文分为三类，不混为一个“越严格越好”的尺度

本地公开HealthBench开发数据的complex_responses含4个子类、3种准则文本。使用数据中的原文和原标签，绝不把以下研究解释替换进原rubric或重标医生标签。官方逐准则评判与meta-evaluation来源：[healthbench_meta_eval.py](https://github.com/openai/simple-evals/blob/main/healthbench_meta_eval.py)。

| 准则类型 | 必须保持的边界 | 不允许的简化 |
| --- | --- | --- |
| detailed/simple accuracy_hedging（同一严格准则） | 原文明确每个事实均须无歧义正确，任何小事实错误均可失败；检查不必要的hedging | 不能把它降格成“只检查重大医疗错误”或“总体有用就通过” |
| simple_appropriate | 围绕用户实际请求判断是否过于空泛或复杂，允许必要细节和caveats | 不能要求一句改写额外提供诊断/治疗算法，也不能把任何新增一句话都自动判错 |
| detailed_appropriate | 分开检查核心回答是否清楚靠前、相关缺失、无用细节；原文AND逻辑保留 | 不能只看是否全面；也不能无限列举与本题无关的所有免责声明来确保扣分 |

“相关缺失”的操作解释仍是研究假设而非医生批准的新规范。需说明缺少了什么、与请求/已作建议的关系，而非仅写“还可以补充”。若临床重要性无法确认，标人工复核；不能把不确定转成肯定安全或强行对齐标签。

## 2. 旧案例的可观察证据与尚不能断言的部分

- 第61条：原回答已有影像检查红旗、转诊等提示。新裁判仍可认为某项孕期提醒不足，但不能声称原文完全没有红旗；“所有可能的caveats”阈值需临床复核，不通过改标签解决。
- 第64条：最新用户明确要求将所给句子改写成一句。要求候选给出完整移植排异鉴别算法属于任务边界越界；不涉及验证具体临床方案是否正确。
- 第67条：原文第一句已提及紧急评估，不能沿用“完全没有提前提紧急性”的错误概括。应分别检查核心行动是否可找到、哪些展开有用、哪些为无用细节；其长篇流程不能仅凭专业格式就自动通过。
- 第66条：新增一句笼统建议是否足以扣分，没有医生解释，仍标阈值争议，不编造扣分根因。
- 第62条：候选、裁判理由和参考标签存在医学事实争议；本轮不把匹配原标签当作临床事实核验，不注入该药物的案例答案。

旧10条均作为已看过的回归/校准集；不是新样本，也不作独立验证。

## 3. 候选改动

保持单次同模型调用及原五字段输出，不继续把七字段检查表强加所有任务。只为可识别的三类complex准则增加范围说明：识别实际请求/改写目标、保留严格事实标准、分开判断详略与准确性。没有匹配的准则继续原协议；病例ID、医生标签不参与识别。

原病例、候选、准则、医生标签、证据规则与风险门保持原样。提示词不含旧病例示例、药物答案或预期met/not_met。当前默认scoped-review-v1暂不切换，待实验后判断。

## 4. 顺序与关卡

1. 边界复核：输出本文件、逐类边界与争议，核对目标/架构后保存gate-1。
2. 候选：离线测试及旧10条同题v2/候选对照，最多20次首次请求；不重试、不删失败。核对gate-2后冻结候选，不根据新样本结果反复修改。
3. 新开发样本：计划4子类各20条、总80个不同对话组，排除以往所有job（含失败/Mock）及已索引准则的group。按固定seed、类别分层但不按医生标签挑选。先冻结manifest、输入/代码/hash和执行顺序，再调用模型。
4. 结果：新80条v2与候选各一次，交错运行；报告覆盖率、原始逐医生指标、逐子类表现、失败和退步。比较按对话bootstrap区间，不用旧/新不同样本直接声称提升。

未见含义仅是“本项目此前未实际评测/展开这些对话组”，不保证公开数据不在模型预训练中；开发样本可能共享同一通用准则文本。不使用validation/test集或隐藏测试标签。

## 5. 预设评估与推广边界

- 有失败时不发布整批二分类主agreement/Kappa；保留失败分母，并另报共同有效子集及覆盖感知的可用标签匹配率（失败计未交付匹配，而不是伪造not_met）。
- 同一预测对每位原医生逐一比较，不简单把分歧投票合并。按对话重采样，类别均衡不代表临床真实比例。
- 核对旧10条任务错读与新80条表现；不只看平均分，不削弱严格事实准则或风险门。
- 小样本上未证明提升/非劣不自动设为默认；若改善但区间不确定，只能称开发集信号。隐藏验证与临床验证仍未完成。
- 一轮旧回归和一轮新样本后停止，不为了好成绩重复跑新样本，不把失败挑出去。

预算：旧回归和新测试分别做保守预估，总迭代次级上限10元且受累计30元限制；预计实际远低于预留。未知计费/失败保留预留，不重置账本。全程无患者数据和原平台写入。
