## 按顺序完成、核对、再继续

1. 引用：新增版本化候选位置集合。重复引文不得任选第一处，不虚构唯一定位；仅当各候选原文一致时接受为“多位置、需复核”。无出处或不同规范化原文仍拒绝。离线测试及同旧输出回放后保存gate-1。
2. 安全：新增有来源、窄适用范围的确定性风险筛查及人工复核门；不把模式匹配冒充完整医学知识，不改医生标签或模型原判。命中风险时保留研究分数但不放行可用汇总分。测试否定、引用、成人、未知年龄等边界后保存gate-2。
3. 复杂回答：只添加单Agent逐条准则检查的实验协议，不新增第二Agent。区分内容相关的必要缺失与无限追加要求，检查任务、核心回答优先级和无用细节。固定开发样本、原标签、随机交错A/B，不反复挑输出；出现退步保留旧默认。测试与实验后保存gate-3。
4. 检索方案：说明现有病例绑定准则不具备跨病例通用适用性；设计适用性元数据、人工审核、准则选择金标准、必检项覆盖与检索隔离测试。仅交付方案/契约，不宣称已建成临床通用Rubrics库。保存gate-4。
