# 逐项证据模板 v1.0

用途：人工评审表，非模型运行输出格式。所有结论留空，不预填医生标签、研究建议或模型结论。按病例独立复制；阶段2不能覆盖阶段1。Markdown供填写，JSON供结构化记录。

## 记录头

- Review ID：
- reviewer_id（自选匿名编号）：
- 专业/相关经验：
- 阶段（1 独立初判 / 2 来源辅助复判 / 3 分歧裁定）：
- 规范版本：review-scoring-v1.0
- 材料版本/接收日期：
- 开始/完成时间（含时区）：
- 是否看过原标签、既有审计或模型判断（是/否/不确定，及何时）：
- 利益冲突/超出专业范围：
- 阶段1冻结文件哈希（阶段2填写；阶段1留空）：

## A. 任务与准则

- 最新真实用户请求及上下文位置：
- 任务性质与受众；哪些仍未知：
- 原准则中全部必选义务（逐条复制/编号，保留 AND/OR）：
- 需要先裁定的准则解释问题（如无也明确记录）：

## B. 回答主张清单（逐项复制）

- claim_id：
- 原句与位置：candidate_output 或 context 第几 turn；quote、start_char、end_char、重复序号：
- 主张类型（医学事实 / 条件计划 / 患者属性 / 出处归属 / 忠实改写 / 非事实表达）：
- 条件、否定、单位、时间、阈值与适用范围：
- 与哪条义务相关；需不需要外部事实核查，为什么：
- 已核查/待核查状态（缺少来源不自动等于错误）：

## C. 逐项义务与证据（每项必选义务一份，可关联多项主张）

- obligation_id / 原准则条文：
- 关联 claim_id：
- 回答/上下文证据及位置；若是遗漏，写明检查范围和缺项，不引用虚构空句：
- 来源 ID、URL或材料名称、章节/表格/段落；额外来源的取得日期与版本：
- 证据原句或精确概述（明确区分摘录与解释）：
- 适用性：applicable / conditional / not_applicable / unclear；原因：
- 支持关系：supports / contradicts / insufficient / not_applicable；推理：
- 义务状态：pass / fail / unresolved / not_applicable；依据：
- 若 not_applicable，原准则允许排除的依据（必选项不得静默豁免）：
- 为什么影响本条判分；是决定性失败还是未决：
- 尚需补充什么；与来源冲突如何处理：

## D. 单条准则结论（不得预选）

- criterion_decision：met / not_met / unable_to_determine
- 决定性理由及关联 obligation_id / claim_id：
- 全部必选项是否已覆盖；未完成项及影响：
- 置信度：低 / 中 / 高；理由（未经校准）：
- 是否仍需专业复核、哪些问题需要谁裁定：

## E. 阶段2/3补充（初判必须保留）

- 初判冻结文件位置与 SHA256：
- 看过的来源及新增自查来源（包括不支持原先观点的材料）：
- 本次结论与初判是否相同；变化原因，哪些新证据/准则解释产生影响：
- 仍未解决的分歧/来源缺口：
- 若裁定，保留各人的原意见并独立记录裁定人、理由、日期；不得覆盖原 benchmark 标签：

## 禁止做法

不以“搜索不到”证明错误；不以合法引用证明语义正确；不从缺少患者信息猜造事实；不把有安全提醒写成完全没有；不把单条准则结论冒充六维评分或临床放行。阶段1如需外查，记录暴露并转为单独的来源辅助记录，不冒充未辅助初判。
