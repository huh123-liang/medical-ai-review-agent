# 非默认影子适配层 v1（仅离线）

本轮授权：增加可开关旁路、逐项证据独立保存、离线验证；不新增付费调用、不改原平台、不改变既有流程/API/计分。7条案例继续 unresolved，不生成新标准答案。

## 1. 所处位置与开关

代码位于 `E:\AI agnet\experiments\item-evidence-shadow-v1\`。没有被 src/medical_jury 引用，没有修改 Provider、Workflow、API、Model Registry、默认配置或启动入口。**已完成离线可用的旁路模块，未完成线上接线；此限制是有意保留的。**

`ShadowAdapter()` 默认关闭，环境变量不会自动开启。关闭时不检查输入、不加载逐项检查器、不创建存储。独立CLI必须显式传 `--enable-shadow` 才会读取输入；旧 Start-Agent 及API不会因此启动影子流程。

开启后只接受调用方提供的本地快照、既有主结果和候选JSON。没有网络、模型客户端、生成器回调或重试推理接口；不能触发新的DeepSeek请求。

## 2. 旁路行为

主结果 → 保持原样返回。

旁路另做：冻结输入 → 固定版本逐项检查器 → 校验/复核诊断 → 专用本地存储。

- `passthrough(primary_result, ...)` 返回同一个主结果对象，不追加字段、不改原判、不改复核标记或正式分数。影子异常转成独立回执；不向主流程抛出普通影子异常。
- `observe(...)` 返回影子回执，不是旧API响应；成功、关闭、重复、冲突、失败分别可见。`last_receipt` 按线程隔离。调用方仍需消费/保存失败回执，不能把旁路失败默认为成功。
- 候选校验通过仍为 NeedsReview，`clinical_release=false`、`benchmark_export_eligible=false`、`official_score=null`。这是结构记录，不是医学认证或临床放行。
- 影子层故障不影响主结果，是**旁路的失败隔离**，不是放宽原系统安全门；本轮没有改原安全策略。

## 3. 独立存储及追溯

只允许写入 `E:\AI agnet\data\shadow-item-evidence-v1\` 下的独立 `shadow.sqlite`，不连接正式 jury.sqlite。模型输出不能指定目录，路径在调用层配置且限制在专用命名空间。

记录包含：请求ID、协议版本、时间、离线材料类型、主结果哈希、完整快照哈希、候选哈希、逐项候选字段、独立检查结果和诊断码。主结果正文不复制。合法候选按原字段保存；无效候选只保存哈希、长度和诊断，不从旧理由推导新证据。

完整快照哈希也覆盖 task_hint，补足原候选四项绑定以外的可复现信息；重建快照校验防止额外标签字段、被改动的原文、来源目录或版本混入。检查器文件SHA256固定为第11轮版本；变更需新版本，不静默加载。

相同请求ID+相同内容只保存一次；ID复用但内容变化，返回冲突且不覆盖原记录，调用方需使用新的尝试ID。SQLite事务与禁止修改/删除的触发器保护应用层追加历史。存储异常/锁/损坏被报告为旁路失败，不覆盖记录、不自动迁移、不自动重新生成候选。

这不是加密或对管理员的防篡改保护；机器拥有者可绕过程序。Windows目录权限继承现有设置，未来真实患者数据接入前仍须评估访问权限、加密、保留期与审计。哈希不等于去标识化，也不证明医学关系正确。

## 4. 数据边界与失败记录

- 输入快照最多2MB，候选JSON最多96KB，不静默截断；既有40主张/12义务/48来源配对的实验界限不变。
- 元数据严格白名单；医生标签不属于快照输入。候选的来源关系仍是模型声明，不能靠存储或哈希升级为事实。
- 检出常见密钥/令牌形态时不保存相应正文，只保留指纹和诊断。该筛查有限，不是全面泄漏防护或患者信息脱敏。
- 无候选输出：记录 legacy_requires_new_instrumentation，不填新字段、不把历史任务追溯改失败。
- 有候选无快照：记录未检查；不能自造Rubrics/义务清单。
- 协议无效：记录结构错误，与医学not_met分开；旧主结果照旧。
- 不能写库：回执仅给稳定诊断码，不回显异常正文、凭据或输入。此时不能保证失败已持久化，须由外层保留回执；本轮离线报告会保存这些测试结果。
