# 公开版本与复现边界

本仓库是独立Agent工程的白名单导出版本，不是整个电脑工作目录的备份。当前维护入口为本目录文档；旧设计规范和历次研究脚本保留在原位置，便于追踪研发过程。

## 包含什么

- 当前 `src/medical_jury` 核心、核心测试、合成示例及安装入口。
- 逐项证据契约、默认关闭的影子适配层、候选Prompt与盲评实验代码。
- 迭代脚本、原始设计笔记、项目目标/架构/流程/进度/失败/后续计划。
- 不含病例正文或标签的聚合试验结果、离线核验入口和未启用的CI模板。

## 不包含什么

凭据、运行数据库、向量索引、真实患者资料、下载的基准数据、医生逐例标签、原始模型回答、本地审查材料和运行日志均不上传。GitHub上的源码不是原始研究数据全集，也不能替代官方数据许可。

公开代码没有修改原项目核心、默认API或原平台；导出版本新增公开文档、可移植核验工具和测试依赖声明，并仅在导出的测试文件中给依赖未再分发来源快照的一项测试增加“缺少快照则跳过”的分支。存在快照时仍执行原完整性检查，不跳过过期或损坏的材料。其他原Python源码按字节保留，避免破坏影子层对证据契约的SHA校验。

## 哪些内容可以直接复现

安装后可以运行核心/实验纯离线测试、合成Mock、CLI/API，以及自行下载公开基准后的准备流程。无来源快照的干净仓库应收集437项：436通过、1项明确跳过（不是437项通过）。安装依赖与下载公开数据需要网络；核验测试本身阻断外部网络且不调用收费模型。

`scripts/` 和实验 `verify.py` 中部分历史重放需要未公开的旧报告、冻结清单或作者目录。它们是保留的研究过程，不承诺 fresh clone 能重建所有历史实验。不要为了通过它们补造医生标签、旧回答或实验材料。

## 如何验证本次导出

运行 `python tools/check_publication.py` 检查文档、敏感文件与聚合字段；运行 `python tools/run_offline_checks.py` 在新建的忽略目录内执行隔离测试。执行结果保存在本地 `reports/`，不提交原始日志。

本次实际核验汇总见 [RELEASE-VERIFICATION.json](RELEASE-VERIFICATION.json)。工程测试通过只代表对应代码契约通过，不代表医学判断达到临床使用要求。
