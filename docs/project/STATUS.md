## 最新实测

第15轮：14个不同validation对话组，7主题各2组，29次原医生标签比较。基线13条有效，对应27次比较：13次一致（48.15%），Macro-F1=0.480769，Cohen Kappa=0.045455。另1条因证据数组6项超过5项而格式失败；整批主指标保留为空。

新三态B1候选前3次均在2400输出token处截断，触发停机，其余11条未运行，不能计算一致性。没有改标签、改Prompt后重跑或推广该候选。

本轮17次真实尝试保守费用0.808553元，作者本地项目累计17.419981元（30元上限）。公开仓库不携带作者账本；其他使用者新建账本不代表作者费用被重置或共享额度。

## 工程测试与医学成绩必须区分

此前416项离线工程测试通过（245核心+71契约+36影子+64候选），第15轮另有21项离线抽样/指标测试通过。它们不是437例医疗验证，也不能据此声称医学判断准确。公开发布包的当前实际测试结果见`docs/project/RELEASE-VERIFICATION.json`，与历史数量分开记录。

7条既有争议案例仍未决，没有新的医生裁定；本仓库不包含其病例材料、原标签或评审包。详见[最新评测口径](EVALUATION.md)和[后续优先级](ROADMAP.md)。
